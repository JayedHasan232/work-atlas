# Name and brand

> Stub. A fuller policy will follow once the project has a legal home.

The code (`AGPL-3.0-or-later`) and the data and text (CC BY-SA 4.0) are free to copy, change and run.
Forks are welcome. The name **Work Atlas**, the Bangla name **কাজ**, and any future logo are handled
differently, so that people always know which site is the community-maintained original.

**You may**
- say that your project is "based on Work Atlas" or "uses Work Atlas data". The licenses require this
  attribution anyway.
- use the name to talk about the project, for example in articles, research or teaching.

**Please don't**
- run a modified public deployment under the name Work Atlas or কাজ. Pick a different name.
- suggest that your site, product or organisation is official, endorsed, sponsored or run by Work Atlas
  when it is not.
- use the name or logo in ads, or in ways that suggest Work Atlas recommends a training centre,
  employer or product. Work Atlas stays neutral: sponsors never change data or recommendations.

Questions go to the maintainer (see [README.md](README.md)).
