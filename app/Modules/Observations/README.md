# Observations

Numbers about work in Bangladesh: income, demand and costs.

- **Owns:** observations by region, period and source (currency, min/median/max, sample size,
  method); private worker submissions (Phase 2).
- **Rules:** never invent a number; no source means `null`. Money is a range with region, period and
  source. Individual submissions stay private; only aggregates above a minimum count are published.

See [the module rules](../README.md).
